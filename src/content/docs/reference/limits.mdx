---
title: Limits
description: Size and count limits for snippets.
---

| Limit                    | Value                      |
| ------------------------ | -------------------------- |
| Code per snippet         | 64 KB (UTF-8 bytes)        |
| Total code, all snippets | 512 KB (UTF-8 bytes)       |
| Number of snippets       | 100                        |
| Name length              | 200 characters             |
| Change log shown         | Latest 100 entries         |

Saving past a limit, or with an invalid path pattern, shows a validation error in the form and
nothing is saved.
