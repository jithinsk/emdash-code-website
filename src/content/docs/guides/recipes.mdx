## Google Analytics 4

Full guide: [Google Analytics 4](/how-to/google-analytics/)

**Placement:** Head · **Priority:** 10

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

## Google Tag Manager

Full guide: [Google Tag Manager](/how-to/google-tag-manager/)

GTM needs two snippets.

**1. Loader.** Placement: Head · Priority: 5

```html
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-XXXXXXX');</script>
```

**2. No-script fallback.** Placement: Body start

```html
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-XXXXXXX"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
```

## Search engine verification

Full guide: [Search engine verification](/how-to/search-console-verification/)

**Placement:** Head · **Include paths:** `/`

Verification only needs the home page, so include just `/`.

```html
<meta name="google-site-verification" content="your-token" />
<meta name="msvalidate.01" content="your-token" />
```
