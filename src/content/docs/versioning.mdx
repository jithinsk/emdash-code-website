---
title: Versioning
description: How releases are numbered and what counts as breaking.
---

The package follows [semver](https://semver.org/).

**Adding a capability is a major version.** Native plugins have no consent prompt on upgrade, so a
minor or patch release never widens what the plugin can do.

Releases are published to npm from GitHub Actions using npm trusted publishing, with provenance.

- [Releases on GitHub](https://github.com/jithinsk/emdash-header-footer-code/releases)
- [Package on npm](https://www.npmjs.com/package/emdash-header-footer-code)
